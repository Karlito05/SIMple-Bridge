# SIMple Bridge

**A Complimentary tool for [Telemetry LMU](https://github.com/Karlito05/TelemetryLMU).**

## Quick start

1. Download the `.exe` from the [releases](https://github.com/Karlito05/SIMple-Bridge/releases)
2. Put it somewhere where you won't accidentally delete it!
3. Put `%command% & sleep 5 && path/to/proton/running/lmu/ run /path/to/SIMpleBridge.exe` into your LMU launch options.

## Building

## Prerequisites

- Rust
- Rust x86_64-pc-windows-gnu toolchain

## How to build

1. Clone this repo: `git clone https://github.com/Karlito05/SIMple-Bridge.git`
2. Change directory into the root folder of the project: `cd ./SIMpleBridge`
3. Build with: `cargo build --release --target x86_64-pc-windows-gnu`
